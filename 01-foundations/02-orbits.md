# Understanding orbits

An orbit is a trajectory shaped by gravity. A circular orbit has constant radius; an elliptical orbit has varying radius.

| Term | Meaning |
| --- | --- |
| Periapsis | Closest point |
| Apoapsis | Farthest point |
| Inclination | Tilt relative to a reference plane |

For a circular orbit of radius $r$ around a body with gravitational parameter $\mu$:

$$
v=\sqrt{\frac{\mu}{r}}
$$

See [transfers](../02-navigation/01-transfers.md) for an application.
